# 弧光短剧创作工作台

弧光是一个本地优先的短剧制作工作台原型，围绕剧本、镜头、参考素材、视频生成、审片和 ARC 剪辑交接组织项目数据。它把可追溯的制作依据放在每集和每镜上，帮助创作者定位问题并进行单镜返修。

## 本地运行

需要 Node.js 与 FFmpeg。运行：

```sh
node arc-comfy-server.cjs --port 8768
```

按终端地址在浏览器打开。仓库不包含剧本、项目备份、角色/场景定妆图或生成回片。导入项目资料保存在浏览器本地存储中，媒体由创作者自行管理。

## 工作流

1. 导入剧本文件，预览分集识别与映射后再写入项目。来源登记仅保存文件名、SHA-256、导入时间和分集操作；不另存原稿副本。重复文件或重复追加需要明确确认。
2. 在分集里拆分场次与镜头，并维护剧本原句、镜头目的、表演、构图、运镜、连续性及美术参考。分析建议先作为草稿，保留原文由创作者确认。
3. 选择已绑定的角色、场景和关键帧参考，整理生成提示词与工作流参数。A/B 对照要求固定同镜输入，仅改变记录中的实验变量。
4. 对回片逐项审查人物、场景、动作、光色、剪辑点和音画同步。结论绑定媒体指纹与制作依据；返修可限定到单镜或时间区间。
5. 将通过片段和镜头清单交给 ARC。素材身份与剪辑范围会被核对，原版本保留以便撤销或回退。

## 代码地图

| 文件 | 作用 |
|---|---|
| `production.js` | 工作台页面与分集、镜头交互编排 |
| `production-project.js` | 项目结构、备份恢复与交接契约 |
| `production-script-import.js` | 本地剧本解析、分集匹配与导入计划 |
| `production-generation.js` / `production-ab.js` | 生成任务准备及受控 A/B 对照 |
| `production-art-review.js` / `production-quality.js` | 审片清单与验收依据 |
| `arc-comfy-server.cjs` | 本地 HTTP/MCP 桥接和 ComfyUI 接入 |
| `arc-comfy-enhancement.cjs` | 本地画质处理任务与结果回接 |
| `qa/` | 解析、数据契约、浏览器交互和回片身份检查 |

## 边界

仓库提供工作流编排和本地桥接，不包含视频模型权重，也不保证远端 GPU、模型服务或第三方工作流可用。声明的预设和参数不等同于运行验证；画质判断必须基于实际回片。项目备份不含原始视频和音频。
